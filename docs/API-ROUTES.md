# PM Tool — API route inventory

Topology v3: browsers reach every route below through the ALB path rule `/api/*`. Routes
marked "API Gateway candidate" are the ones to publish on the API Gateway for external
systems once Infra sets it up (placeholder until then; see docs/HA-READINESS.md).

Generated by `node backend/scripts/route-inventory.js` from the code. Base path for everything
the API Gateway routes: `/api/`. Auth is a Bearer JWT in the `Authorization` header (no
cookies), except the SSO hand-shake, which also uses the short-lived `sso_tx` cookie on
`/api/auth/sso` and must be forwarded. Backend timeouts: `/api/v1/integrations/erp/*` 30 s,
other `/api/v1/*` 5 s; the rest none.

Long or large calls to check against the gateway limits: ERP CR document upload
(`PUT /api/v1/integrations/erp/crs/:crId/document`, multipart up to 30 MB), document upload
(multipart, 10 MB), project import from Excel (multipart, 5 MB), document download
(streams the file, up to 30 MB).
